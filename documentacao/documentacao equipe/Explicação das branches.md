**Documentação das branches**

* **Main: Onde está localizado o projeto final.**

* **Develop: É onde está o projeto mais atualizado para usar como base para novas features.**

* **Features (o que foi adicionado): Os integrantes criam uma nova branch com base na develop mais atualizada, e enviam o projeto com a nova feature para, após testes, darem merge e enviarem para a Develop.**
